

# AI 驱动前端应用生成平台

**前端架构 / AI 应用 Owner**　													2026.01 - 2026.03



### 项目概述

在需求评审与原型验证效率成为团队瓶颈的背景下，主导建设 AI 驱动的前端代码自动生成系统，提升需求验证与原型交付效率。

系统支持：

- 文本需求到代码的自动化生成
- Figma 设计稿结构解析与代码重构生成

系统基于 **LangGraph 多阶段编排架构** 构建生成执行流，实现从需求理解到代码运行的工程化闭环。



### 核心职责与技术实现

**1. 设计多阶段可编排 Agent 架构**

- 将生成流程拆解为阶段节点，构建基于状态流转的执行结构
- 基于 LangGraph 实现多阶段编排流程，提升生成链路的稳定性与可观测性
- 设计节点级重试与错误定位机制，增强复杂生成流程的容错能力



**2. 构建生成结果的结构化约束机制**

- 基于 Zod 统一各阶段输出 Schema，建立结构化生成协议，明确字段边界与语义约束
- 设计多层校验与自动回退机制，降低 JSON 解析失败与结构漂移风险
- 将生成过程从非结构化文本输出升级为可验证、可治理的工程化生成流程



**3. 设计“LLM 推理 + 程序确定性执行”混合架构** 

- 明确推理与执行边界，将语义规划交由 LLM，将确定性构建环节交由程序实现
- 引入程序化依赖与路径规范机制，降低生成不确定性
- 打通生成结果到在线运行的闭环，实现代码产出后的即时验证



**4. 构建生成代码可运行保障机制**

- 基于 import / require 扫描实现依赖自动补全，降低生成代码的缺依赖风险
- 引入 AST 后处理修复策略，增强渲染安全与空值访问容错能力



**5. 构建调试与稳定性增强机制**

- 支持 global / phase / node 级 Mock 开关
- 基于 SSE 构建步骤级 ThoughtChain 展示与版本快照记录
- 支持中间状态追踪与版本快照展示



### 项目成果

1. 构建结构化 AI 生成体系，生成结构解析失败率下降约 60%+，显著提升稳定性与可解释性。
2. 打通代码生成与在线运行闭环，支持在线运行验证，实现即时调试与结果确认。
3. 将需求至 Demo 交付链路由 1~2 天多轮人工协作缩短为分钟级自动生成，原型搭建效率提升约 5~10 倍。
4. 支持文本与 Figma 双入口，覆盖需求预研、产品评审等场景，提升方案验证与演示效率。
5. 架构支持能力节点按阶段扩展，新功能接入无需重构主流程，具备持续演进能力。
